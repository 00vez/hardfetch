# hardfetch --- cli tool

Minimal Windows system info tool.

## Usage

```
hardfetch [options]

  --net      Show network stats
  --version  Show version
  --help     Show help
```

## Features

- OS version
- CPU (name, clock, load, temp)
- NVIDIA GPU (load, clocks, VRAM, temp, power)
- RAM usage
- Disk info
- Network stats (optional)

## Example

```
hardfetch v0.1.0
  OS    Windows 11 Pro
  CPU   Ryzen 7 7800X3D @ 4.2 GHz | 3% | 17°C
  GPU   RTX 5070 | 0% | 29°C
  RAM   6.2 / 31.1 GB
```
